# Browser favicon verification (2026-09-23)

## Scope

- Reuse the existing WiNet mark as the browser tab icon.
- Load the icon through the shared site layout on every page.
- Preserve correct asset URLs at both `/` and the GitHub Pages `/WiNet-Lab/` base path.

## Implementation

- `public/favicon.svg` uses the same path geometry and colors as `src/components/Mark.astro`.
- `src/layouts/SiteLayout.astro` references the icon with the shared `assetPath()` helper. The URL includes a version query so browsers discard route-specific negative favicon cache entries created before the icon was published.
