# Gallery 栏目接口实现（2026-09-22，本地完成，未发布）

## 范围

用户要求新增与 Home/Research 同级的 Gallery 栏目放置团建活动图片，参考 tns.thss.tsinghua.edu.cn/sun/publication.html 的按活动分组照片墙+点击放大做法；图片后续提供，本轮实现数据接口、页面、灯箱与空状态。本地实现，不发布。

## 实现

- 参考：该页为按活动分组（标题+日期）的照片墙，每组一行多张缩略图，点击弹出大图逐张浏览。据此实现同构接口。
- `src/data/gallery.json`：`intro`（页首一句介绍）+ `groups[]`（每活动：稳定 `id`、英文 `title`、`date` YYYY或YYYY-MM、可选 `description`、`photos[]` ≥1 张：`id` 全站唯一、`src` 为 `gallery/<组id>/<照片id>.webp`、英文 `alt`）。当前 groups 为空，页面显示明确占位（Lab photos are coming soon）。
- `src/lib/gallery.ts`：zod schema（组id/照片id唯一、路径与日期格式校验）+ base 适配 `galleryPhotoPath`。
- `src/pages/gallery.astro`：h1+intro+分组（绿色衬线组标题+暖棕日期，风格同站内）、4:3 缩略图网格（auto-fill 自适应、lazy、hover 微放大）；空状态虚线占位框。
- `src/components/GalleryLightbox.astro`：共享 native dialog 灯箱（复用站内模式）——点击缩略图变暗背景显示大图（object-fit contain 不裁切）、组标题说明、左右按钮/方向键切换（循环）、计数、Esc/背景/×关闭、关闭归还焦点至缩略图；数据经客户端脚本从 gallery.json 读取，空 groups 时安全跳过。
- `site.json` 导航新增 Gallery（People 与 Contact 之间）；`[section].astro` 排除 gallery。

## 首批照片填充（同日晚，本地完成，未发布）

用户提供 `resources/gallery/{2024,2025,2026}/` 各1张团建照片（约1707×1280横版），要求按年份填充。处理：sharp EXIF矫正+长边≤1280+有损WebP q82 输出 `public/gallery/{年}/photo-1.webp`（184/118/185KB，1280×960），resources原图未动；三张照片经图像识别核对内容后写入诚实英文标题与alt——Lab dinner 2024（餐桌合影）、Team outing 2025（户外景点合影）、Group photo 2026（校园合影）。gallery.json 三组各1张，空状态消失。

新增 `scripts/check-gallery.mjs`（两种base）：三组标题、3缩略图WebP加载于正确base、空状态移除、灯箱全交互（打开/方向键与按钮切换循环/Esc/背景点击关闭、说明与计数、照片加载）、灯箱开合两态axe零违规、320–1440px无溢出、无失败请求、截图。home.spec 的Gallery断言由空状态改为三组标题+3缩略图。

验证：astro check零错误；两种base构建22页；check-gallery两种base通过；17项Playwright测试、check-base通过；页面/灯箱截图目视通过（[desktop](gallery-2026-09-22-desktop.png)、[mobile](gallery-2026-09-22-mobile.png)、[lightbox](gallery-2026-09-22-lightbox.png)）。本地Git提交，未推送。
