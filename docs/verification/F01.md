## Reproduce here (PowerShell)

```powershell
$env:PATH="$PWD\.tools\node-v24.21.0-win-x64;$env:PATH"
$env:PLAYWRIGHT_BROWSERS_PATH="$PWD\.tools\browsers"
$env:ASTRO_TELEMETRY_DISABLED='1'
npm.cmd run check
npm.cmd run build
npm.cmd test
$env:SITE_BASE='/winet-group/'
npm.cmd run build -- --outDir .tools/base-dist
node.exe scripts/check-base.mjs
Remove-Item Env:SITE_BASE
```

Tests own an isolated server on port 4322. The subpath script owns port 4323. Normal review uses port 4321 and dist/; the subpath build is isolated under .tools/base-dist.

With normal preview running, regenerate images using node scripts/capture.mjs. Optional --reference attempts a live reference capture; it failed with ERR_CONNECTION_RESET. Native browser control was also unavailable, so local Chromium provided implementation tests and screenshots.
