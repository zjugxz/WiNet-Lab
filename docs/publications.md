## 用户可提供的资料

每篇至少提供：完整标题、作者（按发表顺序）、期刊/会议名称、年份。可附 DOI 或论文链接，便于核对。若状态为已接收或预印本，请说明，避免将录用和正式发表混为一谈。

可选：论文展示图、研究主题标签、Paper / Code / Website 链接、是否精选、共同一作或通讯作者标记、需强调的作者。未准备好的选填项可以暂缺；不要求用户预先转换为JSON，普通文本、BibTeX或现有论文列表均可在后续整合。
